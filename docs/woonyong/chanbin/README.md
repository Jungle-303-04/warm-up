## 검토 규칙

- 원격 GitHub와 읽기 전용 git 정보를 기준 근거로 삼는다.
- 기존 로컬 워크트리 수정사항은 건드리지 않는다.
- 커밋 시간은 한국 시간 기준으로 묶는다.
- 날짜별로 구현 작업, 시도, 결정, 수정, 개선, 문제, 다음 행동을 기록한다.
- 구현량뿐 아니라 찬빈이 코드를 이해하고 소유하고 있는지도 함께 본다.
- AI가 학습을 돕고 있는지, 완성 욕심 때문에 이해를 건너뛰게 만들고 있는지도 기록한다.
- 구현 구조가 다이어그램으로 더 명확하면 Mermaid UML 또는 흐름도를 포함한다.
- 폴더명과 파일명은 영어로 쓰되, 문서 본문은 한국어로 작성한다.
