# Notion 개인 계획 동기화 스킬

## 목적

이 문서는 개인 Notion 작업 계획과 현재 git 브랜치, 실제 소스코드 상태를 맞춰 보기 위한 스킬 문서다.

Codex 스킬로 사용할 때는 같은 폴더의 [SKILL.md](./SKILL.md)를 기준으로 한다.

## 사용 시점

- 내 Notion 작업 중 지금 구현해야 할 항목을 찾을 때
- 현재 브랜치의 코드가 Notion 계획과 맞는지 볼 때
- 작업 상태를 `진행 중`, `완료`, `보류 중` 중 무엇으로 둘지 판단할 때
- 코드가 앞서 있거나 계획이 앞서 있을 때 Notion 수정안을 만들 때

## 핵심 흐름

```text
본인 식별
-> 개인 작업 후보 조회
-> 현재 브랜치와 코드 확인
-> 계획과 코드 비교
-> 지금 구현할 항목 설명
-> Notion 또는 코드 수정안 제안
-> 승인 후 반영
```

## 식별 기준

| 근거 | 의미 |
|---|---|
| Notion 현재 사용자 | 가장 강한 본인 식별 근거 |
| Notion 담당자/참여자 | 실행 책임을 판단하는 근거 |
| Notion 작성자 | 작성한 작업노트인지 판단하는 근거 |
| git author | 현재 로컬 작업자와 Notion 사용자를 대조하는 보조 근거 |
| git branch | 관련 작업을 찾는 보조 근거 |

브랜치명이나 작성자만으로 담당자를 확정하지 않는다.
