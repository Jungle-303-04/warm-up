# GitHub Issue Flow

Notion 작업, 회의 후속 조치, 제품 문서를 GitHub issue 흐름으로 연결할 때 쓰는 스킬이다.

Codex 스킬로 사용할 때는 [SKILL.md](./SKILL.md)를 기준으로 한다.

## 사용 시점

- 회의록에서 GitHub issue 초안을 만들 때
- Notion 작업을 GitHub issue로 연결할 때
- 브랜치 이름이나 PR 설명을 정리할 때
- 중복 issue를 피하고 근거 있는 issue를 만들 때
