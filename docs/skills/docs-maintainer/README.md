# Docs Maintainer

문서를 추가, 이동, 삭제, 재정리할 때 쓰는 스킬이다.

Codex 스킬로 사용할 때는 [SKILL.md](./SKILL.md)를 기준으로 한다.

## 사용 시점

- 새 문서를 추가할 때
- 문서 폴더 구조를 바꿀 때
- README 인덱스를 정리할 때
- 낡은 링크나 경로를 찾을 때
- 문서가 중복됐는지 판단할 때
