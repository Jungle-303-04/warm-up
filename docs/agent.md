# Agent

## Scope

- 싱글 에이전트 요청 해석
- 필요 시 RAG 사용
- 질문 응답
- 실행 계획 제안

## Goal

사용자 요청을 하나의 진입점에서 해석하고, 작성/정리/질의응답/실행 계획 제안으로 연결한다.

## Independent Assumption

- 실제 GitHub 실행이 없어도 실행 계획 제안까지만 먼저 개발 가능하다.
- 실제 저장 없이도 입력과 출력 흐름만으로 먼저 테스트 가능하다.
- RAG는 없어도 되고, 있으면 검색 모듈을 호출한다고 가정한다.

## Main Work

- 요청 유형 분류
- 문맥 검색 필요 여부 판단
- 작성 / 정리 / 답변 / 실행 제안 분기
- 사용자 승인 흐름 설계

## Dependency Boundary

- 에이전트는 판단과 제안에 집중한다.
- DB 저장, ChromaDB 업데이트, 외부 API 실행은 시스템 계층 책임으로 본다.
