# Posts And Comments

## Scope

- 게시글 CRUD
- 댓글 CRUD
- 페이징
- 검색
- 태그

## Goal

프로젝트 안에서 문서를 작성하고, 댓글로 소통하고, 검색과 태그로 탐색할 수 있어야 한다.

## Independent Assumption

- 프로젝트 모듈은 이미 존재하거나 `project_id`만 유효하다고 가정한다.
- 인증은 이미 끝났거나 임시 사용자로 대체 가능하다.
- AI 기능이 아직 없어도 게시판 기능만 먼저 완성할 수 있어야 한다.

## Main Work

- 게시글 작성 / 조회 / 수정 / 삭제
- 댓글 작성 / 조회 / 수정 / 삭제
- 목록 페이징
- 제목 / 본문 검색
- 태그 저장과 태그 기반 탐색

## Dependency Boundary

- AI 모듈은 게시글 본문을 읽어 초안 또는 분류 결과만 반환하면 된다.
- 게시판 모듈은 AI가 없어도 단독으로 동작 가능해야 한다.
