# 인물별 작업 분석

이 폴더는 사람을 중심으로 프로젝트 작업 흐름, 구현 내용, 판단 근거, 개선 방향을 정리한다.

## 운영 결정

- 새 Notion DB를 만들지 않고 기존 운영 기준인 `프로젝트`, `회의`, `작업` 연결을 우선한다.
- 문서는 로컬 볼트의 인물별 기록으로 두고, Notion에는 필요한 경우 프로젝트나 작업 본문에서 이 문서를 링크한다.
- 인물 폴더는 `docs/people/{person-id}/` 형태로 만든다.
- 한 사람이 여러 프로젝트를 맡으면 인물 폴더 안에 프로젝트별 분석 문서를 둔다.
- 분석은 칭찬이나 감상이 아니라 코드와 커밋 근거를 기준으로 작성한다.

## 문서 단위

- `README.md`: 인물 프로필, GitHub 식별자, 담당 브랜치, 현재 관찰 포인트
- `{project}-{branch}-analysis.md`: 특정 프로젝트/브랜치 작업 분석

## 분석 템플릿

각 분석 문서는 아래 순서를 따른다.

1. 최신 상태
2. 현재 작업 형식
3. 구현한 것
4. 고려한 것으로 보이는 것
5. 잘한 점
6. 못했거나 위험한 점
7. 개선 우선순위
8. 사용자가 도울 수 있는 행동
9. 근거 링크
