# Projects

## Scope

- 프로젝트 생성
- 프로젝트 목록 / 상세 조회
- 프로젝트 멤버 추가

## Goal

사용자가 협업 공간 단위인 프로젝트를 만들고, 다른 사용자를 멤버로 추가할 수 있어야 한다.

## Independent Assumption

- 인증 모듈이 실제 구현되어 있거나, 임시 사용자 ID로 대체 가능하다.
- 게시글 기능이 아직 없어도 프로젝트만 먼저 구현 가능하다.
- 멤버 권한은 MVP에서 모두 동일하다고 가정한다.

## Main Work

- 프로젝트 CRUD 중 최소 생성 / 조회
- 프로젝트 멤버 추가
- 프로젝트 멤버 여부 확인

## Dependency Boundary

- 게시글 모듈은 `project_id`와 멤버 여부만 필요로 한다.
- 복잡한 권한 체계는 이 모듈 책임이 아니다.
